Adjust typing timing, cursor movement, drag duration, and sequence pacing.

Advanced settings

These controls are for users who understand interaction timing and pointer movement. The defaults are the project's tested baseline. Changing settings may cause websites to treat activity as automated, block it, or show a CAPTCHA. No values guarantee that a website will accept an interaction. Never use these controls to bypass anti-bot checks.

DSH Web connection

Local DSH Web address the extension pairs with. Change the port here when DSH Web listens somewhere other than http://127.0.0.1:3080, save, then pair again from the extension popup. After a DSH Web restart the extension re-pairs automatically while a tab at this address is open.
